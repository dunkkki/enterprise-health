# RAG 智能问答助手 — 需求分析

## 1. 项目背景

企业健康管理平台积累了体检数据、风险评估规则、干预方案等大量健康知识。但员工有问题时（"血压偏高怎么调理"），只能自己上网搜——信息不准、和体检结果脱节。

本模块在平台内嵌入一个 AI 健康助手，员工用自然语言提问，系统从健康知识库中检索相关内容，交给大模型生成带来源引用的回答。

## 2. 目标用户

| 角色 | 使用场景 |
|------|------|
| 普通员工 | 查看体检报告后问健康建议，如"甘油三酯偏高饮食上注意什么" |
| 部门主管 | 查看部门风险数据后问干预建议，如"如何组织减重干预计划" |
| HR 经理 | 问企业健康政策相关问题 |
| 管理员 | 管理知识库文档，上传/删除/同步 |

## 3. 核心功能

| 编号 | 功能 | 优先级 | 说明 |
|------|------|:---:|------|
| F1 | 智能问答 | P0 | 用户输入自然语言问题，AI 基于知识库回答 |
| F2 | 来源引用 | P0 | 回答下方显示引用了哪篇文档的哪一段 |
| F3 | 知识库加载 | P0 | 系统启动时自动加载健康知识文档 |
| F4 | 对话记忆 | P1 | 记住上下文，支持连续追问（"能说具体点吗"） |
| F5 | 知识库管理 | P1 | 管理员上传新文档、删除旧文档，自动重新向量化 |
| F6 | 拒绝瞎编 | P2 | 知识库里找不到相关内容时，明确告知用户而非编造 |

## 4. 用户故事

**故事 1：员工查完报告后问健康建议**
emp01 登录 → 查看体检报告 → 发现甘油三酯偏高 → 点开 AI 助手 → 输入"甘油三酯偏高怎么办" → AI 回答具体的饮食和运动建议，下方注明来源是哪份健康指南。

**故事 2：HR 准备干预计划**
hr01 登录 → 看到技术部多人血压偏高 → 打开 AI 助手问"如何组织高血压干预计划" → AI 综合知识库给出步骤建议。

**故事 3：管理员上传新知识**
admin 登录 → 打开知识库管理 → 上传一份《2026年企业健康管理指南》PDF → 系统自动解析、切片、向量化 → 知识库更新完成，新问题能引用新文档。

## 5. 业务边界

**做什么：**
- 回答健康知识类问题（饮食、运动、慢病管理、体检指标解读）
- 回答干预方案类问题（减重计划、戒烟方案、心理辅导）
- 引用具体来源，不瞎编

**不做什么：**
- 不直接开药方或诊断疾病（那是医生的事）
- 不代替规则引擎做风险评估（数值判断继续用规则引擎）
- 不处理非健康领域的问题（回答"不在知识范围内"）
- 不记忆用户隐私数据（每个会话独立，不关联用户身份）

## 6. 验收标准

| 编号 | 验收项 | 标准 |
|------|------|------|
| A1 | 基本问答 | 问"血压偏高饮食注意什么"，3秒内返回有来源引用的回答 |
| A2 | 拒绝瞎编 | 问"火星天气怎么样"，回答"未找到相关知识"而非编造 |
| A3 | 上下文 | 先问"血压偏高怎么办"，再追问"能说具体点吗"，能基于上一轮继续回答 |
| A4 | 文档同步 | 上传一篇新文档后，相关问题能从新文档里检索到 |
| A5 | 来源引用 | 每条回答下方至少有 1 条来源引用，包含文档名 |
